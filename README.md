One original fortune-cookie line for a software developer, written for the
[Fortune Cookie Wisdom for Developers](https://make.fun/bounty/u-gentle-koala-60-fortune-cookie-wisdom-for-developers-025ccf44)
bounty on make.fun. A judge playing a tired senior engineer picks the line
that makes it smile and nod.

## The fortune

> Write tonight's code as if the tired engineer reading it at 3 a.m. is you — because it will be.

The line is true about a developer's day — late-night debugging, inherited
code, estimates that outlive their authors — and it turns on a quiet twist:
the stranger you are writing for is your own future self.

## How it works

`main.py` (Python 3.13) writes exactly that one line to `/output/entry.txt`:
a single line of UTF-8 text, 95 characters, no trailing newline.

```sh
python3 main.py
cat /output/entry.txt
```
